Caption fonts for qrc-gen. Self-hosted woff2 subsets (Latin + Latin Extended, so c/s/z with carons work).
Source: Fontsource 5.3.0 packages of Google Fonts, merged and subset with fontTools. License: SIL OFL 1.1.

- inter-700.woff2 / inter-OFL.txt
- playfair-display-700.woff2 / playfair-display-OFL.txt
- nunito-700.woff2 / nunito-OFL.txt
- jetbrains-mono-700.woff2 / jetbrains-mono-OFL.txt
- anton-400.woff2 / anton-OFL.txt

Only the chosen font is fetched, at runtime, from this folder. No CDN.
